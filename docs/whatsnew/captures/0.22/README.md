# What's New 0.22 capture sources

These PNGs are real IntelliJ IDEA 2026.2 (262.8665.258) screenshots with the locally built Hexana 0.22 plugin. They are generated only by the `screenshot`-tagged `HexanaWhatsNew022CaptureTest`, excluded from the normal UI suite.

| Asset | Capture method | Visible state |
| --- | --- | --- |
| managed-il.png | captureManagedAssembly | Expanded managed type, resolved IL instructions, and matching Portable PDB source-line directives |
| apk-classes.png | captureApkClasses | Classes from both classes.dex and classes2.dex, with DEX filter and search |
| http-replay.png | captureHttpReplay | Captured HTTP request replayed against a local HTTP server, with successful response and JSON body |

The managed fixture is the repository's `sample-clr-portable.exe` and matching PDB. The APK and PCAP fixtures are generated by the capture helper; the replay server runs locally and requires no external service or credentials.

Build the plugin ZIP, then run only this release's source captures:

```sh
HEXANA_USE_LOCAL_PLUGIN=true HEXANA_LOCAL_PLUGIN_ZIP=/absolute/path/to/hexana-0.22.zip \
./gradlew :ui-driver-tests:captureWhatsNewScreenshots -PtestIdeType=IntellijIdea \
  --tests 'org.jetbrains.hexana.ui.HexanaWhatsNew022CaptureTest.captureManagedAssembly' \
  --tests 'org.jetbrains.hexana.ui.HexanaWhatsNew022CaptureTest.captureApkClasses' \
  --tests 'org.jetbrains.hexana.ui.HexanaWhatsNew022CaptureTest.captureHttpReplay'
```

An optional `HEXANA_CAPTURE_IDE_HOME` points to an unpacked IDE containing its matching JBR, avoiding a second distribution download. Linux needs an operational display/window manager and standard fonts/GUI libraries. This run used the maintained `hexana-intellij-ui-jdk25` image, JDK 21 for project toolchains, and the IDE's matching JBR 25.0.2-b410.29.

After generation, rebuild the ZIP and run `captureWhatsNewPage` alone with `AIR_ARTIFACTS_DIR` set. It opens `hexana.showWhatsNew` in the real IDE and stores overlapping overview/details presentation viewports separately from these source images. Inspect the complete sequence for coverage before selecting review attachments.
